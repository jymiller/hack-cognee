LOOPING LAB / THE FULL SDLC

Make the factory faster with every loop.

Hackathon Prep is the repository name. Looping Lab is the learning system: one cumulative brain, a reusable setup, and a complete build-and-review cycle.

DEFINE & DESIGN

Ideate

Choose the problem, expected behavior, acceptance checks, and the smallest useful solution.

Beginning
IMPLEMENT & VERIFY

Build

Turn the idea into software, run checks, prepare the demo, and preserve execution evidence.

Middle
EVALUATE & IMPROVE

Review

Compare the result with the goal. Keep corrections and reusable lessons for the next event.

End → next beginning

Measure time to first runnable build, time to a verified answer, and how much useful work is reused. Measurements are still to be collected.

LIVE DEMO / THE SYSTEM

A remembered method becomes a product choice.

The saved method requires one actor, one problem, one outcome, and an observable check. It shapes every Scope Goblin answer.

  1. 01Enter an oversized pitch
  2. 02Apply the saved method
  3. 03Return one tiny action
  4. 04Check the result

The game uses deterministic rules and a curated saved lesson. The browser edition runs locally in the viewer’s browser; the original runs in an ordinary Docker container.
